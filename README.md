# قيمي: نظام المتعلمين (متوسطة لبيد بن ربيعة)

أحد أنظمة النواة الرقمية. يعمل على قاعدة النواة (Supabase) ويشارك جلسة الدخول مع بقية الأنظمة، بهوية النواة نفسها (`core.css` والترويسة والتذييل).

## الهيكل
- `site/`: الموقع الثابت (GitHub Pages عبر `.github/workflows/pages.yml`).
- `site/assets/config.js`: إعدادات الاتصال بقاعدة النواة (مفتاح publishable فقط).
- `supabase/migrations/`: سكربتات القاعدة (بادئة جداول النظام `qm_`).

## الحالة
المستودع مجهّز بالهوية وصفحة الدخول الموحدة. المحتوى الوظيفي بانتظار وصف البرنامج.
